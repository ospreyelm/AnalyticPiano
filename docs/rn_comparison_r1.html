How to read this table

NCT beat (pink): music21 chordify() produced a vertical slice at this beat, but When in Rome has no chord label here — meaning the human analyst treated one or more notes at this moment as non-harmonic (passing tone, neighbor, suspension, etc.). The "chord" is an artefact of chordification, not a real harmonic event.

Differs from WiR (yellow): music21 produced a different label than the human analyst for what is genuinely a harmonic beat. This is the core RN analysis quality gap.

FB analysis: Figured bass is computed independently from bass + key — no RN reasoning involved. The raw stack (e.g. 8/5/3) and abbreviated form (e.g. 5/3) are always shown regardless of NCT status, because FB labels sounding intervals, not harmonic function.

WiR notation differences: When in Rome uses 6/5 where music21 uses 65, 4/3 where music21 uses 43, etc. These are the same chord — notation convention differs.
