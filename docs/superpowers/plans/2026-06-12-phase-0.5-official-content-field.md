## Design

### Why

Multiple places currently infer "official" from `authored_by = factory@monteverdi.app`.
This is fragile: the factory email is hard-coded in three call sites, the
inference is inconsistent (see `apps/teacher/views.py:316-319` where public
playlists without a factory user fall back to `source = "official"`), and
every later phase needs a reliable filter that doesn't require resolving a
`User` row per request.

Decision D3 settles this: add an explicit `is_official` boolean, backfill it
from factory ownership, and replace all inference.

### Data shapes

#### Exercise (apps/exercises/models.py)

```python
is_official = models.BooleanField(default=False, db_index=True)
```

- `True`: content is part of the official Monteverdi curriculum.
- Default `False` keeps existing non-factory rows unchanged.
- Index enables cheap filtering (`Exercise.objects.filter(is_official=True)`).

#### Playlist (apps/exercises/models.py)

```python
is_official = models.BooleanField(default=False, db_index=True)
```

Same semantics. Playlist and Exercise official state are independent — an
official playlist can contain non-official exercises and vice versa.

### Migration backfill logic

One Django data migration after the schema migration:

```python
FACTORY_EMAIL = "factory@monteverdi.app"

factory_user = User.objects.filter(email=FACTORY_EMAIL).first()
if factory_user:
    Exercise.objects.filter(authored_by=factory_user).update(is_official=True)
    Playlist.objects.filter(authored_by=factory_user).update(is_official=True)
```

Idempotent — running twice sets the same value.

### Consumers to update

| Location | Current pattern | New pattern |
|----------|-----------------|-------------|
| `apps/teacher/views.py:316-319` (`course_detail` playlist list) | Resolves factory user; falls back to `is_public` | `source = "official" if pl.is_official else "mine"` |
| `generate_factory_library --report` (`_handle_report`) | Filters `Playlist.objects.filter(authored_by=factory_user, ...)` | `Playlist.objects.filter(is_official=True, ...)` — no User lookup needed |
| `lab/views.py` `_resolve_author` / save-as-official flow | Sets `authored_by = factory_user` when `saveAsOfficial=True` | Also set `is_official=True` on saved Exercise row(s) |
| `apps/teacher/static/teacher/course_wizard.js` | Reads `source === 'official'` from API (correct, no change needed) | No change — already uses the `source` field from the view |
| `apps/teacher/static/teacher/course_detail.js` | Reads `p.source === 'official'` (correct, no change needed) | No change |

The factory ownership convention (`authored_by = factory@monteverdi.app`) is
kept as a convention for auditability — `is_official` becomes the source of
truth for filtering, not a replacement for the ownership record.

### What is NOT in scope

- Admin UI for toggling `is_official` (Phase 3, curation workbench).
- Superuser promotion flow from `/teacher/play/` (already exists in `lab/views.py`; Phase 1 hardening).
- Playlist `is_official` propagation to child exercises (not automatic; each row managed independently).
- Any API or student-facing surface changes.
