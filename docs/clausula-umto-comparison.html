2. Gaps: What Clausulae Need to Support Traditional Exercises

Clausulae already have correct MIDI grading data. The gaps are all in analysis content — the semantic labels that drive overlays, ? slots, and harmonization targets.

5. Clausula Triple → Harmonic Function Mapping

These mappings are deterministic from clausula type — no music21 needed. Can be hardcoded in the generator.

Simple cadence (τ=0 all voices)

OffsetPositionBass clausula Z₇Roman numeralFigured bass
0.0ANTDo (0)I"" (5/3)
2.0PENSol (4)V"" (5/3)
4.0ULTDo (0)I"" (5/3)

Exact figured bass suffix (root pos vs inversion) must be computed from the full vertical sonority at each offset — the bass pitch alone determines inversion only when all voices are known.

Compound cadence (Discant τ=1)

OffsetPositionBass Z₇Roman numeralNotes
0.0ANT (early)Do (0)IDiscant silent (rest)
1.0ANT (late Discant enters)Sol (4) or DoV or ISuspension begins — harmony may be ambiguous; needs full MIDI check
2.0PENSol (4)VSuspension resolves at ULT
4.0ULTDo (0)IAll voices land

Compound cadences: the suspension dissonance at offset 1.0 (Discant ANT against Bass/Tenor PEN) means that offset should be is_target:false for Roman numeral identification — students aren't expected to label suspension dissonances.

6. Concrete Implementation Plan

⚠ Pre-condition

The Roman numeral / figured bass content must be added inside generate_clausulae_b1.py — not in a separate importer. The generator already owns the Z₇ triple knowledge and the realized MIDI pitches. It is the only place that knows the clausula structure at generation time.

Add _roman_numeral_for_clausula(bass_z7, triple, cadence_type) to generator
Returns the Roman numeral string for a given clausula position. Simple cadences: ANT="I", PEN="V", ULT="I". Compound: offset 1.0 = None (suspension — skip). No music21 needed — pure lookup table from clausula position + bass Z₇ degree.
# In generate_clausulae_b1.py _SIMPLE_RN = {0.0: "I", 2.0: "V", 4.0: "I"} def _roman_for_offset(offset: float, cadence_type: str) -> str | None: if cadence_type == "simple": return _SIMPLE_RN.get(offset) # compound: suspension at offset 1.0 → skip return {0.0: "I", 2.0: "V", 4.0: "I"}.get(offset)
Add _figured_bass_for_sonority(midi_pitches) using existing targets.py logic
apps/exercises/harmonization/targets.py already has figured bass abbreviation logic. Import and call it with the MIDI pitches from the grading slice at each offset. Write result to AnalysisLayer.figured_bass and .raw_figured_bass.
from apps.exercises.harmonization.targets import derive_figured_bass def _figured_bass_for_offset(grading_slices, offset, key): sl = next((s for s in grading_slices if s.offset == offset), None) if not sl or not sl.target_midi_pitches: return None, None bass_midi = min(sl.target_midi_pitches) upper = [m for m in sl.target_midi_pitches if m != bass_midi] fb, raw = derive_figured_bass(bass_midi, upper, key) return fb, raw
Wire into _build_umto() — populate AnalysisLayer + set is_target
Change the analysis= list construction in _build_umto(). Add a harmonic_mode parameter (None for existing behaviour, "roman" / "figured_bass" for new variants). When set, fill roman_numeral / figured_bass and set is_target=True on labellable offsets.
# _build_umto() change: analysis=[ AnalysisSlice( offset=off, content=AnalysisLayer( functional_label=analysis_labels[i], roman_numeral=_roman_for_offset(off, cadence_type) if harmonic_mode else None, figured_bass=_figured_bass_for_offset(grading, off, key)[0] if harmonic_mode else None, raw_figured_bass=_figured_bass_for_offset(grading, off, key)[1] if harmonic_mode else None, ), is_target=(harmonic_mode is not None and _roman_for_offset(off, cadence_type) is not None), unit_tags=[9], # or pass from caller ) for i, off in enumerate(offsets) ]
Add --harmonic-mode flag to management command
python manage.py generate_clausulae_b1 --harmonic-mode roman --unit 9 --overwrite
generates all clausula exercises with Roman numeral targets. Existing playback-only variants are generated unchanged when flag is omitted (no regression).
parser.add_argument("--harmonic-mode", choices=["roman", "figured_bass", "both"], default=None, help="Add Roman numeral / figured bass analysis targets to generated exercises")
Run generate_harmonization on the figured-bass-populated clausula exercises
Once clausula exercises have figured_bass in their analysis slices, the existing generate_harmonization command works unchanged:
python manage.py generate_harmonization \ --source <clausula_exercise_id> \ --author admin@example.com \ --locked-voices B \ --prompt figured_bass \ --min-voices 3 --max-voices 4 \ --public
No changes to generate_harmonization or HarmonizationGrader needed.
Browser-verify each new mode before bulk-generating
Per the roman_from_clausulae spec: passing tests is not enough. After steps 1–4, generate one exercise per mode, open in the student app, and confirm: (a) ? slots appear at correct offsets, (b) choices are correct, (c) grading accepts correct answer. Only then bulk-generate the full B1–B12 range.
