Barline Exercise — How It's Built

Each exercise comes from a folk tune (ABC notation corpus). The pipeline extracts a phrase, computes where barlines go, and stores everything as note indices.

Step 1: Phrase from corpus

Example: 6/8, 2 measures, from ballad20.abc

Notes (by index):
0: 8 1: q 2: 8 3: q 4: 8 5: q ← barline here 6: 8 7: q |

In musical notation: 8 q 8 q 8 q | 8 q
Cumulative quarter-beats after each note:
0.5, 1.5, 2.0, 3.0, 3.5, 4.5 ← hits 3.0? NO. hits...

Step 2: Measure boundary detection

Formula:
bar_quarters = beats_per_measure × beat_quarters

For 6/8: beats_per_measure=2, beat_quarters=3/2 → bar_quarters = 3.0 quarter notes
For 4/4: beats_per_measure=4, beat_quarters=1 → bar_quarters = 4.0 quarter notes
For 9/8: beats_per_measure=3, beat_quarters=3/2 → bar_quarters = 4.5 quarter notes
For 3/4: beats_per_measure=3, beat_quarters=1 → bar_quarters = 3.0 quarter notes

After each note, check: elapsed_quarters / bar_quarters == integer
If yes → barline goes AFTER this note index. Store that index in correct_barline_positions.

Step 4: Grading (note-index comparison)

No beat conversion needed — pure note index comparison:

Student places cursor at note index 3 → placedAt = [3]
correct_barline_positions = [3]
→ CORRECT ✓

Student places cursor at note index 2 → placedAt = [2]
correct_barline_positions = [3]
→ missing: [3], extra: [2] → INCORRECT

Step 5: Beaming

VexFlow generateBeams takes explicit beat groups so beaming matches the meter:

MeterBeam groupsEffect
4/44 × [1/4]Group eighths within each quarter beat
3/43 × [1/4]Group eighths within each quarter beat
6/82 × [3/8]Group 3 eighths per dotted-quarter beat
9/83 × [3/8]Group 3 eighths per dotted-quarter beat
12/84 × [3/8]Group 3 eighths per dotted-quarter beat

Known remaining issue

Beaming within a single beam group works correctly. But VexFlow sometimes draws beam stems going wrong direction for notes outside the staff. This is a VexFlow rendering quirk, not a data issue.

Filter logic (in generate command)

# Skip phrases where any barline crosses a note (syncopation):
expected_barlines = phrase.measures - 1
if len(payload["correct_barline_positions"]) != expected_barlines:
    continue

Data flow summary

ABC corpus file
  → music21 parse → notes list (duration, dots, pitch)
  → corpus_filter.py: slice phrases, filter by level/meter/length
  → barline_exercise_builder.py:
      - compute elapsed quarters per note
      - detect measure boundaries → correct_barline_positions (note indices)
      - store note_beat_onsets (kept for reference, not used in grading)
  → save_umto_barline_exercise() → Exercise DB row
  → ExercisePlaylistOrdered → Playlist

Browser:
  → barline_player.js renders notes via VexFlow
  → cursor moves between note gaps (note indices 0..noteCount-2)
  → on submit: gradeBarlines(placedAt, correct_barline_positions)
      → direct Set comparison, no conversion
