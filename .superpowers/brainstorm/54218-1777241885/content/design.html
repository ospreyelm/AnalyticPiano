QWERTY Label Overlay — Design

HTML badge divs positioned over Raphael SVG. Active only in QWERTY mode.

Keyboard in QWERTY mode (49-key, partial view)

Architecture

  • keyboard.js — builds a .qwerty-labels div after render(), populates it with one badge per key using existing layout data. Show/hide on INPUT_MODE event.
  • key.js — no changes needed (layout data already on each key component)
  • keyboard_shortcuts.js — already has the note→key letter mapping, used to derive badge labels
  • harmony.css — adds .qwerty-labels, .qwerty-key-badge, .qwerty-key-badge.black styles

Position math (per key)

  • White key badge: left = key.calculateOffsetX() + 2px, bottom = 6px, width = keyWidth - 4px
  • Black key badge: left = key.calculateOffsetX() + 1px, bottom = 8px (from black key bottom = 66% height), width = blackKeyWidth - 2px
  • Container: position:absolute; top:0; left:0; pointer-events:none so it doesn't block mouse on keys
