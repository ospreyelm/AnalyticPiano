Voice selection at import time

When duplicating a chorale as a pitch identification exercise, how should the teacher specify which voice to use?

A

Dropdown in the duplicate dialog

A "Duplicate as pitch identification" button opens a small dialog with a dropdown: Voice: Soprano / Alto / Tenor / Bass. One click → one exercise for that voice.

Pros

  • Simple, one action per voice
  • Matches existing duplicate-as-identification pattern

Cons

  • Teacher must press the button 4× to generate all 4 voices
B

Multi-select — generate all voices at once

A dialog lets the teacher check which voices to generate (S / A / T / B). Creates one exercise per checked voice in a single action.

Pros

  • One action to create a full set
  • Consistent naming (e.g. "BWV1.6 – Soprano")

Cons

  • More complex dialog UI
  • Generates multiple exercises — may feel like too much at once
C

Field on the exercise edit form

The duplicate creates a chorale_identification exercise with analysisType: "note_name". A Voice dropdown field on the edit form lets the teacher switch which voice is extracted, updating the exercise in place.

Pros

  • Editable after creation
  • No dialog needed

Cons

  • More complex — voice selection must be re-applied on every save
  • Requires storing both the full score and the selected voice
