HarmonyLab — Platform Meta-Plan

5 phases, sequenced by dependency. Each phase ships independently.

PHASE 1 — UNBLOCK ~1 day · Pure backend · No UI

Fix applySkillFilter unit map

Replace hardcoded Unit 9 allowlist with a UNIT_ALLOWED_ANSWERS map derived from music_theory_taxonomy_with_branches.json. Gates all adaptive content for every unit.

File: exercise_definition.js:37–67  |  Unblocks: Phases 2, 3, 4
PHASE 2 — CONTENT FACTORY ~2 days · CLI + DB

create_unit_playlist management command

Single idempotent command: reads taxonomy → imports Bach phrases → creates Playlist → links exercises. Replaces batch_import_unit9.py one-off scripts forever. Generates units 9–18 from Bach corpus.

CLI: manage.py create_unit_playlist --unit 11 --riemenschneider 21-30 --author admin@x.com --mode roman  |  Unblocks: Phase 3 workbench trigger
PHASE 3 — WORKBENCH ~5 days · Django + HTMX + Alpine.js

Teacher Workbench — full authoring UI

Builds on existing workbench.html stub. Three panels: Import (MusicXML upload or corpus picker), Preview (rendered score + exercise test), Publish (unit assignment, key propagation, mode selection). HTMX for server-rendered fragments. Alpine.js for panel state only.

Key feature: "Generate Unit N" button triggers create_unit_playlist via HTMX POST with live progress stream
PHASE 4 — MOBILE ~3 days · CSS + JS · Student player only

Responsive student player

Student-facing only (teacher tools stay desktop). Score renders at mobile viewport, piano keyboard becomes touch-friendly strip, identification slots stack vertically. No HTMX needed — pure CSS breakpoints + touch event handlers.

Target: iPhone 14, iPad. Not in scope: dashboard, workbench, admin
PHASE 5 — HELP TEXT ~2 days · UMTO field + Claude API

Student help text system

Add help_text field to UMTO schema. Auto-generated placeholder at exercise creation via Claude API (reads score + tags → proposes text). Editable in workbench. Displayed in player as collapsible hint panel.

AI draft: Claude Haiku, one call per exercise at generation time. Human override always wins.

Dependency chain

Phase 1 → Phase 2 → Phase 3 (workbench wraps CLI) → Phase 4 (parallel) → Phase 5 (additive)
Phases 4 and 5 are independent — can run in parallel after Phase 2 ships.
